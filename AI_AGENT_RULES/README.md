# cancer-vive AI Agent Rules

This binder is the repo-local AI instruction kit. Load it before acting, then read the source documents listed in manifest.json when exact detail matters.

## Read Order

1. `ORIENTATION.md` — executable orientation enforcement.
2. `FIRING_ORDER.md` — deterministic movement order for intake, PR/CI/deploy, and closeout.
3. `OPERATING_RULES.md` — durable behavior rules.
4. `METADATA_POST_AND_PRODUCT_RULE.md` — Post vs Product metadata (canonical rule in ai-skills-library).
5. `AGENT_ASSIGNMENTS.md` — who owns which movement.
6. `SKILLS.md` — local skill routing.
7. `HISTORY.md` — durable lessons that should shape future behavior.
8. `CHANGELOG_CONTEXT.md` — release and change context.
