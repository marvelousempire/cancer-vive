# Cancer Vive

Research ledger for the metabolic overlap between type 2 diabetes, the Warburg effect, pseudohypoxia, intermittent hypoxia training, and related spice/extract claims.

This repository is a Handbook Framework Contribution Type house. It is organized with:

- Architecture of Truth / Concise Perspective — how literature is written and reviewed
- Housekeeper — how the house stays clean (sole write authority, corpus, 5W+H)
- Bishop — how staff cards are born (session workers until a Creation Pack exists)
- Historia — idea and session ledger

This is not medical advice, a treatment protocol, or a claim that cancer is a type of diabetes.
